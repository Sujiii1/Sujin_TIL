# Sujin_TIL

> Containers Type

- Array
- List : 인덱스로 데이터에 접근할 수 있으며, 동적으로 크기가 
         조절 가능한 요소를 저장할 수 있다.
- Stack : 후입선출(LIFO) 구조를 가지는 요소를 저장하는 컨테이너.
- Queue : 선입선출(FIFO) 구조를 가지는 요소를 저장하는 컨테이너.
<br/><br/>
- Dictionary
<br/>
<b>* 특징<b>
<br/>
1. 해시 테이블을 기반으로 하기 때문에 빠른 검색 가능 <br/>
2. 순서는 보장이 안되어서, 키 순서대로 접근하고 싶다면 SortDictionary 사용.<br/>
3. 키 기반 데이터 접근으로, 값으로는 접근 불가
<br/>
4. 키에는 null을 불가능 , 값에는 null 허용
<br/>
5. 확장성과 가변적 크기: 요소가 추가될 때마다 동적으로 크기 조정, 
   다양한 크기의 데이터를 저장 가능. 
   <br/>
6. LINQ : LINQ를 사용할 수 있어, 데이터를 필터링하거나 특정 조건을 만족하는 
   키-값 쌍을 찾기 위해 LINQ 쿼리를 활용 가능.
